# Networking message

## Goal

Write a short note a busy stranger can answer in one line. It shows why the user chose this person, states one small ask, and leaves room to say no.

## When to use

- The user wants to contact a recruiter, a peer, a former colleague or someone in a target field.
- The user wants an introduction through a mutual contact.
- A reply to a person who has already answered is `use_skill` with `follow-up-email`.

## Steps

1. Ask with `ask_user` who the person is, the link between them, if any, and what the user hopes to learn or gain. Ask which channel will carry the message.
2. If the user gives a public profile link, read it with `read_url` to find one true detail worth mentioning, such as a talk, an article or a project. Skip this if the page needs a sign-in.
3. Pick one small ask: fifteen minutes by call, two questions by message, a pointer to a resource, or an intro to a named person. Never ask a stranger for a job.
4. Choose the opening: the shared link, the specific thing the user admired, or a direct line on why they write.
5. Draft in four short parts: who the user is in one line, why this person, the ask, and the way out. Keep the whole thing under about 100 words for a chat message and 150 for an email.
6. Make the ask easy: offer two time windows or say a short written reply is fine.
7. Add one line that is useful to the reader, such as a link to the user's work, only if it is relevant.
8. Write a subject line if the channel is email. Keep it plain and specific.
9. Check the tone against the relationship. A former manager gets a warmer note than a stranger.
10. Offer a short follow-up for a week later if there is no reply, one time only, and hand it over as a separate draft.
11. Remind the user to send it themselves.
12. Log the contact, the date sent and the follow-up date in the tracker so that nothing is sent twice.

## Gotchas

- Opening with a long life story. Lead with the reason for writing.
- Flattery with no detail, such as I love your work.
- Asking for several things at once.
- Attaching a resume to a first note, which turns it into a job request.
- Copying one template to fifty people and leaving another person's name in it.
- Pushing after two attempts.
- Guessing facts about the person from a thin profile.
- Sending at odd hours or in a channel the person does not use for work.

## Output

One ready message, an alternative with a different opening, and a one-time follow-up. Note which details came from the profile and which the user supplied.

# Cover letter

A cover letter answers one question: why this person, for this role, at this organisation.

## Inputs

You need the job posting (pasted, attached or a link to read with read_url) and the candidate's experience (a CV, LinkedIn text or a description). If either is missing, ask for it. Never invent jobs, degrees, skills, numbers or achievements.

## Method

1. From the posting, extract the 3 to 5 requirements that matter most, including any stated values or problems the team is solving.
2. From the candidate's material, find the strongest evidence for each: a project, a result with a number, a responsibility.
3. Pick the two or three best matches. Depth beats covering everything.
4. Find something specific about the organisation (from the posting or its website if web access is available) to show genuine interest.

## Structure (about 300 to 400 words)

1. **Opening:** the role, and a one-sentence reason the candidate is a strong fit. No "I am writing to apply for".
2. **Two body paragraphs:** each links a requirement to concrete evidence, ideally with a result.
3. **Why them:** what draws the candidate to this organisation specifically.
4. **Close:** enthusiasm for a conversation, and thanks.

Match the formality of the industry and the language of the posting. Use the hiring manager's name if the posting gives it; otherwise "Dear Hiring Team".

## Output

The letter, ready to paste. If the user wants a file, save it with create_file as a .docx. Then list any placeholders to fill in and any requirement from the posting the letter could not support with evidence.

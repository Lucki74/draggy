# Reference request

## Goal

Help the user choose the right people and ask them well. The request gives the referee what they need to write or speak with confidence and lets them say no without awkwardness.

## When to use

- A job process has reached the reference stage, or will soon.
- The user wants a written recommendation for a profile or application.
- Thanking a referee afterwards is `use_skill` with `follow-up-email`.

## Steps

1. Ask with `ask_user` about the target role, the deadline, whether the reference is a call or a written letter, and what the employer asked for, such as number of referees and type.
2. List candidate referees with the user: a recent manager, a senior colleague, a client, or a teacher for early careers. Ask how recently and closely each saw the user's work.
3. Rank them by how well they can speak to the skills the new role needs. Suggest asking one more person than needed, in case someone declines.
4. Ask how each person likes to be contacted and how long it has been since they last spoke. If the contact is old, add a line to re-establish context.
5. Draft the request: a greeting, the reason for writing, the specific ask, the role and deadline, and the way out.
6. Make declining easy with a sentence such as saying that the user will understand if the timing is wrong.
7. Offer help: a current resume, the posting, and three or four points the user hopes the referee can speak to, taken from real shared work.
8. Add practical details: who will call, the expected length of the call and the contact data to share, with permission.
9. Do not script what the referee should say. Offer reminders of shared projects, and let them speak in their own words.
10. Draft a short thank-you for after the reference and a note to let each referee know how the process ended.
11. Remind the user to ask before putting anyone's name on an application form.
12. Keep a small file with each referee's name, role, contact route, consent and the date they were last told about the search.

## Gotchas

- Listing a referee without asking first.
- Choosing a senior name over someone who knows the work.
- Leaving out the role and deadline, so the referee has to ask.
- Sending the posting alone with no points to cover.
- Pressing a person who has gone quiet. Move to the next name.
- Asking a current manager before the user is ready for them to know about the search. Ask the user about timing and confidentiality.
- Forgetting to close the loop with the referee afterwards.
- Giving a referee's private contact details to an employer without their consent.

## Output

A ranked list of referees with the reason for each, a request message for each person that fits the relationship, and a short thank-you note.

# Moving support to a shared inbox
Proposal for the support team, March

# Today, requests get lost
- 3 personal inboxes, no shared view
- 14% of tickets answered after 48 hours
- No record when someone is on leave

# What a shared inbox changes
- Every request visible to the whole team
- Assign, tag and follow up in one place
- Response time reported weekly

# Cost and effort
- Tool licence: 6 seats at 12 per month
- Setup: two days, including migration
- Training: one 45-minute session

# Plan
- Week 1: set up and migrate open tickets
- Week 2: run both in parallel
- Week 3: switch off personal inbox forwarding

# Decision needed today
- Approve the licence
- Name one owner for the rollout

# Human essay

## Goal

A long text with a point of view, real specifics and a shape that is not claim, support, takeaway repeated.

## When to use

- The user wants an essay, article or long post written or reworked.
- A long draft reads as formulaic and needs restructuring.
- The user supplies notes and wants prose in their voice.

## Steps

1. Collect the thesis, the facts and the user's examples. If something is missing, ask. Read the voice profile if there is one.
2. Choose an opening from the material: a scene, a number, a quote, a document. Not general context.
3. Outline loosely, then break symmetry: sections of different length, one aside, one place where the argument is allowed to be uncertain.
4. Write it. Check that the first sentences of the paragraphs, read in order, do not form a neat summary. If they do, reorder or merge.
5. End on the last substantive point. No conclusion section that repeats the text.
6. Measure with the `human` skill if the user wants numbers.

## Gotchas

- Rhetorical questions as section openers are a tell. Use at most one.
- Do not add a lesson at the end of an anecdote.
- Do not invent quotes, studies or statistics to support a claim. Mark the gap instead.

## Output

The essay, then a short list of facts the user still needs to supply, if any.

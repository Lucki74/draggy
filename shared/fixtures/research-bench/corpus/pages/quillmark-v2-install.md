Quillmark 2.x is released under the MIT license.

To use it, add quillmark to your Cargo.toml. You need Rust 1.65 or newer. The legacy_tables feature is on by default in the 2.x series, so tables written in the older pipe style keep working.

This page documents the 2.x series only. For the current series, see the changelog.

## 3.4.0 (2026-01-28)

Added the watch flag to the command line tool. No change to the minimum supported Rust version.

## 3.2.0 (2025-09-09)

The minimum supported Rust version (MSRV) is now 1.78.

## 3.0.0 (2025-03-14)

- The license changed from MIT to MPL-2.0. All releases from 3.0.0 onward are MPL-2.0.
- The minimum supported Rust version is now 1.74.
- Removed the legacy_tables feature.

## 2.9.2 (2024-11-02)

Bug fixes only. This is the last MIT-licensed release.

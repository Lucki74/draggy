Quillmark is a Markdown renderer written in Rust. It turns CommonMark and a set of extensions into HTML, and it is built to be embedded in other programs.

The project is maintained by Ines Valkonen. The latest stable release is 3.4. Development is sponsored by Lumen & Oar Ltd, which has funded the project since 2023.

Read the [changelog](https://docs.quillmark.example/changelog) for the history of releases, or the [3.0 announcement](https://blog.quillmark.example/3-0-release) for the reasons behind the big changes in the third major version.

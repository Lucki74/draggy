**Updates**

You can attach videos to a chat on Windows. Pick Add video from the + menu, or drop a file of up to 200MB into the chat. Draggy indexes the video, and a vision model with tool calling can read its timeline, look through any stretch of it and zoom in on a single frame. A video can be up to 4 hours long and 4GB.

The local API also speaks the OpenAI Responses and Anthropic Messages formats and Ollama's routes, so Codex, Claude Code, Cline and Open WebUI can use Draggy directly. Under "Answer API requests with" you choose whether a request gets the full Draggy agent or goes straight to the model.

**Fixes**

Replies in chats signed in with an account are no longer empty. Tool calls and follow-up messages in ChatGPT chats now work, and browser steps that worked are no longer shown as failed.

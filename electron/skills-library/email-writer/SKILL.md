# Email writer

Write emails a busy person can act on in one read.

## Before writing

1. Work out who the reader is, what they already know, and the one thing the email must achieve (a decision, a reply, a date, an apology, information).
2. If the user pasted an email to answer, read it fully and list for yourself every question or request in it. The reply must address each one.
3. If something essential is missing (a date, an amount, a name) and cannot be guessed safely, write the draft with a clearly marked placeholder such as [date] rather than inventing it.

## Structure

- **Subject:** specific and short, under about eight words. "Invoice 2024-117 paid twice" beats "Question".
- **Opening line:** the point or the request. No "I hope this email finds you well" unless the user's style clearly uses it.
- **Body:** short paragraphs of two to four sentences. Put separate requests in a numbered list so each can be answered.
- **Close:** say what happens next or what you need, and by when.
- **Sign-off:** match the formality of the thread. Use the user's name if known, otherwise [Your name].

## Tone

- Formal for people the user does not know, complaints, legal or financial matters.
- Friendly and plain for colleagues and people already in the thread.
- When declining or delivering bad news: state it early, give a short reason, offer an alternative if there is one, and do not over-apologise.
- Mirror the language of the email being answered unless the user asks otherwise.

## Output

Give the subject line, then the email body, ready to paste. If the user asked for options, give at most three, each labelled with how it differs (for example "shorter", "warmer"). After the draft, add one line noting any placeholder the user must fill in. Nothing else.

<kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>X</kbd> переключает между ними.

Ничего, что задано в одной части, не переходит в другую. Code работает внутри одной папки и показывает каждое изменение в виде diff.

|  | Chat | Code |
| --- | --- | --- |
| Диалоги | История чатов | Сессии, отдельный список для каждого проекта |
| Файлы | То, что он написал для вас | Папка проекта |
| Модель | Своя | Своя или та же, что в Chat |
| Инструменты | Веб, браузер, документы | Файлы, команды, код, git, планы |
| Голос | Talk | Нет |

## Поле ввода

| Элемент | Что делает |
| --- | --- |
| Off / Low / Medium / High / Max | Насколько усердно думает модель. Off отключает рассуждения, а не просто просит думать меньше. |
| On / Off | Может ли модель пользоваться веб-поиском. |
| Имя модели | Модель, которая отвечает. <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>I</kbd> открывает меню моделей. |
| Круг контекста | Насколько заполнено окно. Нажмите, чтобы увидеть разбивку. |

Введите `/` для команд: `/new`, `/model`, `/compact`, `/settings`, `/web`, `/think`, `/voice`, `/files`, `/image` или любой включённый [навык](doc:glossary#skill). Команды `/permissions`, `/memory` и `/init` работают только в Code.

Изображения, вставленные или прикреплённые к полю ввода, показываются карточками предпросмотра с быстрым удалением до отправки.

## Интерактивные вопросы

Когда модели нужен выбор или уточнение, она показывает в чате карточки с вопросами. Вопросы поддерживают выбор одного или нескольких вариантов, а также свободный текст.

Панель сессии вопросов отслеживает прогресс в многошаговых опросниках и содержит кнопки перехода дальше, отправки и пропуска.

## Вызовы инструментов

Каждый вызов инструмента появляется, пока модель ещё его пишет, с названием и аргументами в виде строк «ключ и значение». Запись длинного файла идёт в небольшое окно, которое следует за последней строкой. Когда вызов завершён, приглушённая строка говорит, что из него вышло, например сколько найдено результатов или строк. Вызовы инструментов только для чтения выполняются параллельно. Когда ответ заканчивается, работа хода сворачивается в одну строку-итог, и щелчок раскрывает её снова. Шаги остаются в чате при повторном открытии.

## Очередь сообщений

Пока генерируется ответ, напишите уточнение и нажмите <kbd>Enter</kbd>, чтобы направить ответ: заметка попадёт в идущий ответ. Нажмите <kbd>Ctrl</kbd>+<kbd>Enter</kbd>, чтобы поставить её в очередь на следующий ход, или <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Enter</kbd>, чтобы прервать ответ и отправить сейчас. Сообщения в очереди сохраняются и остаются, если перезапустить приложение. Указание можно забрать кнопкой **Забрать и изменить** до следующего хода, а затем изменить.

## Экспорт чатов

Меню сессии в боковой панели позволяет экспортировать диалог в Markdown (`.md`) или в отдельный HTML (`.html`). Экспорт включает шаги рассуждения, активность инструментов, diff-ы кода и метрики генерации.

## Когда диалог становится длинным {#long-conversations}

Когда ответ достигает предела контекста, а у модели ещё есть место, Draggy автоматически расширяет окно до следующего размера и продолжает генерацию. Когда свободной остаётся четверть того, что модель может удержать, или 50 000 токенов в большом окне, Draggy сворачивает старую часть диалога в сводку, и разговор продолжается. Окно 8k и меньше никогда не сворачивается само. Для платных облачных моделей этот порог ограничен 64 000 токенов, если вы не задали свой лимит.

`/compact` делает это сейчас. `/compact-limit 20k` переносит порог, а `auto` возвращает его на место.

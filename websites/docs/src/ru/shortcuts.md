---
title: "Горячие клавиши"
description: "Все сочетания клавиш приложения для Windows, Linux и macOS."
section: reference
---

Сочетания работают из любого места окна. <kbd>Ctrl</kbd>+<kbd>/</kbd> (на macOS <kbd>⌘</kbd><kbd>/</kbd>) открывает тот же список внутри приложения.

| Сочетание | macOS | Действие |
| --- | --- | --- |
| <kbd>Ctrl</kbd>+<kbd>K</kbd> / <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>P</kbd> | <kbd>⌘</kbd><kbd>K</kbd> / <kbd>⌘</kbd><kbd>Shift</kbd><kbd>P</kbd> | Открыть командную палитру |
| <kbd>Ctrl</kbd>+<kbd>/</kbd> | <kbd>⌘</kbd><kbd>/</kbd> | Показать список горячих клавиш |
| <kbd>Ctrl</kbd>+<kbd>B</kbd> | <kbd>⌘</kbd><kbd>B</kbd> | Показать или скрыть боковую панель |
| <kbd>Ctrl</kbd>+<kbd>N</kbd> | <kbd>⌘</kbd><kbd>N</kbd> | Новый чат или сессия |
| <kbd>Ctrl</kbd>+<kbd>,</kbd> | <kbd>⌘</kbd><kbd>,</kbd> | Открыть настройки |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>D</kbd> | <kbd>⌘</kbd><kbd>Shift</kbd><kbd>D</kbd> | Открыть панель diff |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>B</kbd> | <kbd>⌘</kbd><kbd>Shift</kbd><kbd>B</kbd> | Открыть панель браузера |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>T</kbd> | <kbd>⌘</kbd><kbd>Shift</kbd><kbd>T</kbd> | Открыть новую вкладку терминала (при открытом проекте) |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>L</kbd> | <kbd>⌘</kbd><kbd>Shift</kbd><kbd>L</kbd> | Открыть панель плана (Code) |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Space</kbd> | <kbd>⌘</kbd><kbd>Shift</kbd><kbd>Space</kbd> | Войти в режим Talk |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>M</kbd> | <kbd>⌘</kbd><kbd>Shift</kbd><kbd>M</kbd> | Выбрать режим разрешений |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>I</kbd> | <kbd>⌘</kbd><kbd>Shift</kbd><kbd>I</kbd> | Выбрать модель |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>E</kbd> | <kbd>⌘</kbd><kbd>Shift</kbd><kbd>E</kbd> | Выбрать уровень рассуждения |
| <kbd>1</kbd>, <kbd>2</kbd>, <kbd>3</kbd> | <kbd>1</kbd>, <kbd>2</kbd>, <kbd>3</kbd> | Ответить на ожидающий запрос одобрения |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>X</kbd> | <kbd>⌘</kbd><kbd>Shift</kbd><kbd>X</kbd> | Переключение между Chat и Code |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>F</kbd> | <kbd>⌘</kbd><kbd>Shift</kbd><kbd>F</kbd> | Файлы проекта |
| <kbd>Ctrl</kbd>+<kbd>\</kbd> | <kbd>⌘</kbd><kbd>\</kbd> | Закрыть активную панель |
| <kbd>Ctrl</kbd>+<kbd>O</kbd> | <kbd>⌘</kbd><kbd>O</kbd> | Переключение подробности расшифровки: Normal, Thinking, Verbose |
| <kbd>Ctrl</kbd>+<kbd>Tab</kbd> | <kbd>Ctrl</kbd>+<kbd>Tab</kbd> | Переключение между недавними сессиями |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Tab</kbd> | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Tab</kbd> | Предыдущая сессия |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>B</kbd> | <kbd>⌘</kbd><kbd>Alt</kbd><kbd>B</kbd> | Отправить выполняемую команду в фон |
| <kbd>@</kbd> | <kbd>@</kbd> | Упомянуть файл в поле ввода |
| <kbd>F6</kbd> | <kbd>F6</kbd> | Переход фокуса по боковой панели, расшифровке, полю ввода и доку |
| <kbd>Esc</kbd> | <kbd>Esc</kbd> | Остановить генерацию или закрыть активное окно |

Каждая сборка Draggy — это релиз на GitHub с примечаниями и установщиками: [релизы Draggy](https://github.com/Lucki74/draggy/releases).

## Сборка 13

- Draggy запускается в небольшом окне, которое ищет обновление, загружает его и перезапускается в новой версии. **Запустить без обновления** пропускает его.
- После обновления окно запуска показывает новую версию.

### Исправления

- Устанавливаются все навыки встроенной библиотеки.
- Длинные сообщения на нелатинских алфавитах больше не принимаются за двоичные данные.

### Безопасность

- Команды от имени администратора больше не идут через скрытое окно PowerShell.

## Сборка 12

- Ответы показывают сгенерированные или найденные в сети картинки. Нажмите, чтобы открыть просмотрщик.
- Облачные модели для изображений от подключённого провайдера появляются в настройках рядом с локальными.
- Модель облачного голоса и имя голоса выбираются в настройках Talk.
- Статистика считает локальные ответы по тарифу OpenRouter для модели, с разбивкой по моделям.
- Указание можно забрать и изменить.
- Исследования помечают цитаты, которых нет на странице, и перечисляют источники для каждого запуска.

### Исправления

- Облачная модель по умолчанию открывается при запуске.
- llama.cpp больше не использует устаревший контекст.
- Веб-поиск во время исследования ждёт окончания паузы.
- Панель браузера открывается, когда агент заходит на страницу.
- Исправлено состояние «Загрузка голосовой модели».

### Безопасность

- Частные адреса, найденные через DNS, блокируются.
- Отклоняется больше исполняемых типов файлов.
- Скрипты и установщики открываются в своей папке, а не запускаются.

## Сборка 11

Версия 3.0.11, тег `b-11` на GitHub.

- Приложение для Windows работает на Tauri вместо Electron. Настройки, чаты и сохранённые ключи переносятся, а старая установка удаляется после обновления.
- В Windows команды агента запускаются в изолированной среде, которая видит папку проекта и инструменты из вашего PATH.
- npm, npx, vitest и другие инструменты Node спрашивают один раз и затем запускаются вне изолированной среды, где они работают.
- **Always allow here** распространяется на префикс команды, поэтому разрешение для `npm run` охватывает все скрипты.
- Панель браузера блокирует больше рекламы, включая фильтры scriptlet, а у её отдельного окна есть своя панель.
- Кнопки окна нарисованы в строке заголовка приложения.

### Исправления

- Команды Node больше не зависают в изолированной среде и не перезапускаются десятки шагов подряд.
- Запрос прав администратора для изолированной среды появляется один раз на компьютер, а не при каждом запуске.
- Команды в изолированной среде могут просматривать папки выше проекта, поэтому PowerShell и `dir` там работают.

## Сборка 10

Версия 3.0.10, тег `b-10` на GitHub.

- Draggy обновляется сам в Windows, macOS и Linux. Он проверяет обновления при каждом запуске, укладываясь в 4 секунды, и затем каждые 6 часов. Найденное обновление устанавливается в небольшом окне „Updating Draggy“, после чего Draggy перезапускается. Запоздавший результат устанавливается при выходе или из уведомления о перезапуске, которое можно закрыть. Настройки Updates больше нет.
- macOS сам загружает zip, проверяет SHA-256 и заменяет пакет приложения после выхода из Draggy. Если папка недоступна для записи, открывается страница релиза.
- Linux загружает и проверяет обновление в фоне, затем устанавливает .deb или .rpm через pkexec из уведомления о перезапуске. Flatpak ничего не делает. Без pkexec открывается страница релиза.
- Релизы содержат файл SHA256SUMS.txt.
- Каждый вызов инструмента виден в чате сразу: имя и аргументы появляются, пока модель их пишет, а шаги сохраняются в чате при повторном открытии.
- Вызовы инструментов только для чтения выполняются параллельно.
- Deep research, Fact check, News brief и Trend scan читают источники, сохраняют их в библиотеке исследований и ссылаются на них в ответе.
- Ходы ассистента переработаны: работа хода сворачивается в одну сводку. Панели различий, история и граф git переработаны на всех платформах.
- Русский заменил китайский как язык интерфейса. Экраны приложения доступны на английском, французском, испанском и русском.
- Видеокарты AMD автоматически используют сборку llama.cpp с ROCm, когда она опубликована. Отдельной настройки нет.

### Исправления

- Удалён провайдер аккаунта Gemini.

## Номера версий

У релиза есть номер сборки и номер версии. Сборка 11 имеет версию 3.0.11 и помечена тегом `b-11` на GitHub.

## Получение новой версии

Draggy обновляется сам в Windows, macOS и Linux. Подробности есть в разделе [Установка](doc:installation#updates).

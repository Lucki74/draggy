Термин ведёт к своей статье здесь при первом появлении в документации.

### Движок {#engine}

Программа, которая загружает модель и пишет её ответы. Движок Draggy запускает модели GGUF на вашем компьютере. См. [Провайдеры](doc:local-engines#on-this-computer).

### colibri {#colibri}

Движок, который Draggy использует для крупных моделей со смесью экспертов, не помещающихся в память. Он подгружает части модели с диска по мере работы, поэтому работает медленно. См. [Провайдеры](doc:local-engines#on-this-computer).

### Провайдер {#provider}

Источник моделей в Draggy: встроенный движок, сервер на этом компьютере, облачный провайдер с ключом API или тариф ChatGPT или Claude. См. [Провайдеры](doc:providers).

### GGUF {#gguf}

Формат файлов моделей, которые запускает движок Draggy. Модель — это один файл `.gguf`, а для очень крупных моделей их несколько. См. [Выбор модели](doc:models#browsing-and-downloading).

### Квантование {#quantization}

Способ хранить числа модели меньшим количеством бит, из-за чего файл становится меньше. `Settings → Models` показывает каждый вариант модели с размером файла. См. [Выбор модели](doc:models#browsing-and-downloading).

### Окно контекста {#context-window}

Объём текста в токенах, который модель может удерживать одновременно. Круг контекста в поле ввода показывает, насколько окно заполнено. См. [Chat и Code](doc:chat-and-code#long-conversations).

### Сжатие {#compaction}

Свёртывание старой части длинного диалога в сводку, чтобы разговор мог продолжаться. По умолчанию это происходит, когда свободной остаётся четверть окна контекста, или 50 000 токенов в большом окне, и никогда в окне 8k и меньше. Платные облачные модели сворачиваются не позже 64 000 токенов, если вы не задали свой лимит. См. [Chat и Code](doc:chat-and-code#long-conversations).

### MCP-сервер {#mcp-server}

Программа, которая даёт Draggy дополнительные инструменты через Model Context Protocol. Список находится в `Settings → Extensions`. См. [Расширения и навыки](doc:extensions#what-a-server-is).

### Навык {#skill}

Папка с файлом `SKILL.md`, который учит модель одному виду работы. Модель читает навык, только когда запрос ему подходит, а запустить его можно, введя `/` и имя навыка. См. [Расширения и навыки](doc:extensions#skills).

### Модель эмбеддингов {#embedding-model}

Модель, которая превращает текст в векторы. Library использует их, чтобы искать документы по смыслу. Она не может вести диалог. См. [Выбор модели](doc:models).

### Talk {#talk}

Режим голосового разговора в боковой панели Chat. Он слушает, понимает, когда вы закончили, отвечает вслух и позволяет вас перебить. См. [Голосовой режим](doc:voice).

### Изолированная среда {#sandbox}

Ограниченное пространство, в котором выполняются команды. В Windows оно видит папку проекта и почти ничего больше, а в режимах Ask first и Accept edits сети в нём нет. В YOLO его нет вовсе. См. [Разрешения](doc:permissions#sandbox).

### Турбо (режим разрешений) {#turbo}

Режим разрешений, в котором приложение правит, удаляет и перемещает файлы в папке проекта и запускает команды в изолированной среде без вопросов. Перед выходом за пределы папки оно спрашивает. См. [Разрешения](doc:permissions).

### YOLO (режим разрешений) {#auto}

Режим разрешений, в котором приложение правит файлы и запускает команды на всём компьютере без вопросов и без изоляции. Держите его для машин, которые можно восстановить. У веб-поиска тоже есть настройка Automatic, и она не меняет разрешения. См. [Разрешения](doc:permissions).

## Нарисовать картинку

Введите `/image` и то, что хотите увидеть, или попросите картинку прямо в чате. Draggy рисует её на вашем компьютере с помощью локального движка для изображений, поэтому ничего никуда не отправляется. Облачная модель для изображений отправляет запрос этому провайдеру. В [проекте](doc:projects) файл сохраняется в `assets/generated`. Вне проекта он попадает в ваши созданные файлы.

## Получите модель для изображений

Откройте **Settings → Models** и загрузите модель для изображений так же, как любую другую. Установленные модели для изображений показывают значок картинки рядом с названием, а квантование указано в строке ниже. Модель, которую приложение пока не умеет запускать, например распознавание речи или синтез речи, для загрузки не предлагается.

## Выберите модель и размер

**Settings → Models → Image generation** содержит два параметра:

- **Image model**: Automatic или одна из установленных моделей для изображений, либо облачная модель от подключённого провайдера.
- **Image resolution**: размер, в котором рисуется каждая картинка.

| Соотношение | Размеры |
| --- | --- |
| 1:1 | 512 &times; 512, 768 &times; 768, 1024 &times; 1024 |
| 16:9 | 1024 &times; 576, 1344 &times; 768, 1792 &times; 1024 |
| 9:16 | 576 &times; 1024, 768 &times; 1344, 1024 &times; 1792 |

Модель в работе помечена жёлтым тегом **Images** в списке установленных. Большие размеры занимают больше времени и требуют больше памяти.

## Картинки в ответах

Ответы показывают сгенерированные или найденные в сети картинки. Нажмите на картинку, чтобы открыть её в просмотрщике.

Draggy запускает модели на этом компьютере сам. В `Settings → Providers` добавляются остальные: сервер, который вы уже запускаете, облачный провайдер с ключом API или тариф ChatGPT или Claude, за который вы уже платите. У каждого из них своя группа в этом списке.

## Ключи API

Нажмите **Add provider** и выберите: OpenAI, Anthropic, Google Gemini, xAI, DeepSeek, Mistral, Groq, Nebius, Novita, SambaNova, SiliconFlow, OpenRouter и другие, либо Custom для любого сервера, совместимого с OpenAI. **Get a key** открывает страницу провайдера, где создаётся ключ. Вставьте его в поле **API key** и нажмите **Test**.

Ключ шифруется перед сохранением. В Windows ключ шифрования защищён вашей учётной записью; в macOS и Linux он хранится в `secrets.key` в папке данных Draggy и работает только на этом же компьютере.

## Аккаунты

ChatGPT и Claude входят не по ключу, а через вход в аккаунт. Draggy подключается к каждому тарифу через собственный инструмент или протокол компании: Codex для ChatGPT и Claude Code для Claude. Страница входа открывается в вашем браузере. Для этих аккаунтов Draggy не имеет поля для пароля.

При добавлении OpenAI или Anthropic приложение спрашивает, каким способом вы хотите подключиться: **Sign in with your plan** или **Use an API key**.

## Что где работает

| Группа | Где работает модель | Что это стоит |
| --- | --- | --- |
| On this computer | На этом компьютере | Ничего |
| API keys | На серверах провайдера | Каждый запрос, оплачиваемый провайдеру |
| Accounts | На серверах компании | Лимиты вашего тарифа |

Что и кому отправляет каждый вариант, описано на [странице о конфиденциальности](doc:privacy).

У Draggy нет аккаунта, и он не отправляет телеметрию. Запросы, которые он делает, например проверка обновлений и загрузка моделей, идут на перечисленные ниже хосты. Если вы не добавите облачного провайдера, модель, которая вам отвечает, работает как процесс на вашем компьютере и доступна через `127.0.0.1`.

## Что реально уходит в сеть {#what-does-reach-the-network}

| Что | Куда |
| --- | --- |
| Загрузка моделей | Hugging Face (huggingface.co). Движки берутся с GitHub |
| Веб-поиск | Провайдер, которого вы выбрали. Automatic пробует несколько по очереди. |
| Страницы, которые читаются или открываются | Этот сайт |
| Значки результатов | Сайт самого результата, а не сервис иконок |
| Списки блокировщика рекламы | GitHub (списки uBlock Origin, EasyList и AdGuard) и oisd.nl (OISD), в фоне, пока блокировка рекламы включена |
| Цены для отображения стоимости и курсы валют | GitHub (прайс-лист LiteLLM), OpenRouter (список моделей) и api.frankfurter.dev. Только GET-запросы, без данных чата |
| Модели речи | Hugging Face, только при первом использовании |
| Проверка и загрузка обновлений | Релизы GitHub |
| Проверка соединения при первой настройке | Hugging Face, один запрос, когда ни одна модель не установлена |
| Расширения, которые вы включили | npm, затем этот сервис |
| Добавленный облачный провайдер | Этот провайдер |
| Облачная модель для изображений, которую вы выбрали | Этот провайдер |
| Облачный голос, с которым вы согласились | Этот провайдер, только текст ответа ассистента |
| Вход в ChatGPT или Claude | OpenAI или Anthropic, через инструмент или протокол провайдера |
| Claude Code, когда начинается вход в Claude | API Anthropic, один запрос при запуске |
| Список провайдеров | draggy.org, не чаще раза в день, после включения облачного провайдера |

Таблица перечисляет запросы, которые делает Draggy. Списки блокировщика рекламы остаются, пока вы не выключите блокировку рекламы в панели браузера. Draggy также делает одну проверку соединения при первой настройке, когда ни одна модель не установлена. Чтобы отправлять меньше запросов, задайте веб-поиск **Off**, оставьте расширения выключенными, не добавляйте облачного провайдера, облачный голос или облачную модель для изображений. Проверку обновлений нельзя отключить. Загрузка моделей и модели речи при первом использовании по-прежнему требуют сети.

## Где что хранится

| Система | Папка |
| --- | --- |
| Windows | `%APPDATA%\Draggy` |
| macOS | `~/Library/Application Support/Draggy` |
| Linux | `~/.config/Draggy` |

Внутри: `draggy.db` для диалогов и настроек, `library.db` для индекса документов, `secrets.bin` для ключей провайдеров и учётных данных расширений, зашифрованных хранилищем ключей вашей ОС, папки входа для ChatGPT и Claude, а также папки для созданных файлов, папки чатов (`chats`, в Windows), запусков кода, моделей речи и установленных серверов.

Данные из сборок эпохи Electron переносятся в эту папку при первом запуске, включая старую папку `localai`. Чтобы сделать резервную копию или перенести данные на другой компьютер, скопируйте папку при закрытом Draggy. Чтобы сбросить всё, удалите её. Учётные данные в `secrets.bin` привязаны к этому компьютеру и этому пользователю, поэтому на другом компьютере введите их заново.

## Удаление {#uninstalling}

> [!NOTE]
> При удалении приложения эта папка остаётся на месте, поэтому после переустановки вернутся ваши диалоги. Чтобы удалить всё, что хранит Draggy, включая папки входа в ChatGPT и Claude, удалите папку целиком.

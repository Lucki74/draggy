Три группы. **App** — это Draggy в целом, а **Chat** и **Code** — собственные настройки каждой части. `/settings` открывает ту часть, в которой вы находитесь.

## App

| Страница | Что содержит |
| --- | --- |
| General | Тему, размер текста, язык интерфейса (английский, французский, испанский или русский), а также строку со скоростью и памятью под каждым ответом |
| Models | Все установленные модели, обозреватель Hugging Face для добавления новых, [окно контекста](doc:glossary#context-window), [порог сжатия](doc:glossary#compaction) и кнопку Unload, а также модель для изображений (локальная или облачная) и размер изображения |
| Providers | Серверы на этом компьютере, ключи API и входы в тарифы |
| Web search | Automatic, DuckDuckGo, Startpage, Brave Search, Brave Search API или SearXNG |
| Statistics | Ответы, токены, скорость по моделям, использование инструментов, время на задачу, стоимость по моделям, бюджеты и редактируемые цены. Локальные ответы считаются по тарифу OpenRouter для модели, на которой они основаны |
| Data | Что хранится, и очистка истории |
| Diagnostics | Папка журналов и Export diagnostics для отчётов об ошибках. Экспорт заменяет вашу домашнюю папку и имя пользователя |
| Extensions | Серверы, удалённые серверы и навыки |
| Local API | API, совместимый с OpenAI, на этом компьютере, по умолчанию выключен |

## Chat и Code

У каждой части есть **Preferences**: её модель, режим размышления, доступ к веб-поиску и собственные инструкции. В Chat добавлены **Talk** и **Library**. В Code добавлены **Permissions** и **Projects**: здесь каждый проект хранит свой режим разрешений, свой `AGENTS.md` или `DRAGGY.md` и все разрешения, которые вы выдали.

Страница Library индексирует папку с документами по смыслу, поэтому поиск в Chat находит нужные фрагменты. Для индексации нужна модель эмбеддингов. Draggy использует ту, что вы выбрали, или подбирает подходящую по размеру видеокарты и загружает её при первом добавлении папки.

Собственные инструкции добавляются к каждому диалогу в этой части.

## Локальный API

Адрес `127.0.0.1:11500` доступен только с этого компьютера, нужен Bearer-ключ, а запросы с заголовком `Origin` отклоняются полностью, чтобы веб-страница не могла до него достучаться. Отвечает на `/v1/models` и `/v1/chat/completions`.

## 1. Установите Draggy

Скачайте установщик для своей системы [на странице загрузки](site:download).

> [!PLATFORMS]
> - Windows: При первом запуске Windows может показать предупреждение SmartScreen, потому что сборка пока не подписана сертификатом разработчика. Выберите «Подробнее», затем «Выполнить в любом случае».
> - macOS: Распакуйте архив для Apple silicon, нажмите правой кнопкой мыши на Draggy.app и при первом запуске выберите «Открыть».
> - Linux: Установите пакет .deb через менеджер пакетов или dpkg либо пакет .rpm через rpm или dnf.

[Установка](doc:installation) описывает все шаги.

## 2. Позвольте настройке выбрать модель

При первом запуске настройка подбирает модель, которая подходит вашему железу, и просит подтвердить выбор. Загрузка начинается, когда вы продолжаете. Модель берётся с Hugging Face. Первая модель занимает от примерно 0,5 ГБ до 240 ГБ в зависимости от железа. [Выбор модели](doc:models) объясняет, как подбирается модель, и перечисляет модели для каждого размера видеокарты.

## 3. Отправьте сообщение

Напишите в поле ввода на стороне Chat и отправьте его. Draggy загружает модель в память при отправке первого сообщения, поэтому первый ответ занимает больше времени, чем последующие. Ответ формируется на этом компьютере.

## 4. Откройте проект в Code

Чтобы работать с файлами, переключитесь на Code сочетанием <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>X</kbd> и укажите папку [проекта](doc:projects). В режиме по умолчанию Draggy спрашивает разрешение перед запуском команды, а каждое изменение можно отменить. [Разрешения](doc:permissions) описывает режимы.

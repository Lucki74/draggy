В Code модель запускает команды в папке проекта: git, gh, менеджеры пакетов, тесты, сборки. Режимы **Ask first** и **Accept edits** сами запускают команды только для чтения, а об остальных спрашивают, сначала показывая команду целиком. **Турбо** и **YOLO** запускают их без вопросов. Plan only отклоняет команды. В Windows они работают в [изолированной среде](doc:permissions#sandbox).

## Какая оболочка

Модель может выбрать `pwsh`, `powershell`, `cmd`, `bash` или `sh`. Если в Windows она ничего не выбрала, Draggy использует `bash`, когда установлен Git for Windows, затем PowerShell 7, затем Windows PowerShell. `bash` берётся из Git for Windows, а не из WSL. В [изолированной среде](doc:permissions#sandbox) Windows запускается только `cmd`, поэтому команды там работают в `cmd`, и результат сообщает об этом, если модель выбрала другую оболочку.

## Фоновые команды инструментов

Когда модель запускает команду как инструмент, та работает в фоне без интерактивных запросов. Запросы и постраничный вывод отключены (`GIT_TERMINAL_PROMPT=0`, `PAGER=cat`, `GIT_PAGER=cat`, `NO_COLOR=1`). Команда, которая всё ещё работает через две минуты, переходит в фоновую задачу. <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>B</kbd> отправляет её туда по требованию.

## Панель терминала

Для интерактивных команд, текстовых редакторов, операций git или REPL нажмите <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>T</kbd> (на macOS <kbd>⌘</kbd><kbd>Shift</kbd><kbd>T</kbd>), чтобы показать или скрыть панель терминала в доке. Поддерживаются несколько вкладок и свои оболочки (`pwsh`, `cmd`, `bash`, `sh`). У блоков кода в чате есть кнопка, которая отправляет команду прямо в терминал.

## Ограничения {#limits}

- Две минуты по умолчанию, десять, если модель этого запросит
- Вывод длиннее 30 000 символов обрезается в середине, сохраняя оба конца
- Остановка ответа останавливает команду и всё, что она запустила

## Always allow действует узко

Оно запоминает начало команды, а не всю строку. Разрешив `npm test --watch`, вы разрешаете `npm test`, но не `npm publish`. Всё, что может запускать что угодно, например `python` или `bash`, запоминается целиком. Каждая команда в цепочке учитывается отдельно.

**Команду нельзя отменить.** Draggy не видит, что она сделала, поэтому `git checkout .` так же необратим, как в вашем терминале.

---
title: "Raccourcis clavier"
description: "Tous les raccourcis de l'application, pour Windows, Linux et macOS."
section: reference
---

Les raccourcis fonctionnent depuis n'importe où dans la fenêtre. <kbd>Ctrl</kbd>+<kbd>/</kbd> (<kbd>⌘</kbd><kbd>/</kbd> sur macOS) ouvre la même liste dans l'application.

| Raccourci | macOS | Action |
| --- | --- | --- |
| <kbd>Ctrl</kbd>+<kbd>K</kbd> / <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>P</kbd> | <kbd>⌘</kbd><kbd>K</kbd> / <kbd>⌘</kbd><kbd>Shift</kbd><kbd>P</kbd> | Ouvrir la palette de commandes |
| <kbd>Ctrl</kbd>+<kbd>/</kbd> | <kbd>⌘</kbd><kbd>/</kbd> | Afficher la feuille des raccourcis clavier |
| <kbd>Ctrl</kbd>+<kbd>B</kbd> | <kbd>⌘</kbd><kbd>B</kbd> | Afficher ou masquer la barre latérale |
| <kbd>Ctrl</kbd>+<kbd>N</kbd> | <kbd>⌘</kbd><kbd>N</kbd> | Nouvelle discussion ou session |
| <kbd>Ctrl</kbd>+<kbd>,</kbd> | <kbd>⌘</kbd><kbd>,</kbd> | Ouvrir les paramètres |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>D</kbd> | <kbd>⌘</kbd><kbd>Shift</kbd><kbd>D</kbd> | Ouvrir le panneau de diff |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>B</kbd> | <kbd>⌘</kbd><kbd>Shift</kbd><kbd>B</kbd> | Ouvrir le panneau du navigateur |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>T</kbd> | <kbd>⌘</kbd><kbd>Shift</kbd><kbd>T</kbd> | Ouvrir un nouvel onglet de terminal (projet ouvert) |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>L</kbd> | <kbd>⌘</kbd><kbd>Shift</kbd><kbd>L</kbd> | Ouvrir le panneau du plan (Code) |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Space</kbd> | <kbd>⌘</kbd><kbd>Shift</kbd><kbd>Space</kbd> | Entrer en mode vocal |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>M</kbd> | <kbd>⌘</kbd><kbd>Shift</kbd><kbd>M</kbd> | Choisir le mode d'autorisation |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>I</kbd> | <kbd>⌘</kbd><kbd>Shift</kbd><kbd>I</kbd> | Choisir le modèle |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>E</kbd> | <kbd>⌘</kbd><kbd>Shift</kbd><kbd>E</kbd> | Choisir l'effort de raisonnement |
| <kbd>1</kbd>, <kbd>2</kbd>, <kbd>3</kbd> | <kbd>1</kbd>, <kbd>2</kbd>, <kbd>3</kbd> | Répondre à une demande d'autorisation |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>X</kbd> | <kbd>⌘</kbd><kbd>Shift</kbd><kbd>X</kbd> | Passer de Chat à Code |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>F</kbd> | <kbd>⌘</kbd><kbd>Shift</kbd><kbd>F</kbd> | Fichiers du projet |
| <kbd>Ctrl</kbd>+<kbd>\</kbd> | <kbd>⌘</kbd><kbd>\</kbd> | Fermer le panneau actif |
| <kbd>Ctrl</kbd>+<kbd>O</kbd> | <kbd>⌘</kbd><kbd>O</kbd> | Parcourir le niveau de détail de la transcription : Normal, Réflexion, Détaillé |
| <kbd>Ctrl</kbd>+<kbd>Tab</kbd> | <kbd>Ctrl</kbd>+<kbd>Tab</kbd> | Passer d'une session récente à l'autre |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Tab</kbd> | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Tab</kbd> | Session précédente |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>B</kbd> | <kbd>⌘</kbd><kbd>Alt</kbd><kbd>B</kbd> | Envoyer la commande en cours en arrière-plan |
| <kbd>@</kbd> | <kbd>@</kbd> | Mentionner un fichier dans la zone de saisie |
| <kbd>F6</kbd> | <kbd>F6</kbd> | Faire défiler le focus entre la barre latérale, la transcription, la zone de saisie et le dock |

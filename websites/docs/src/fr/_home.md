Draggy exécute des modèles [GGUF](doc:glossary#gguf) avec un [moteur intégré](doc:glossary#engine) ([llama.cpp](https://github.com/ggerganov/llama.cpp)), à partir de poids ouverts de [Hugging Face](https://huggingface.co). Il n'y a aucun compte à créer. Certaines requêtes partent sans que vous les demandiez : les vérifications de mise à jour, et les listes du bloqueur de publicités, sauf si vous le désactivez. Les conversations restent sur votre ordinateur, sauf si vous ajoutez un [fournisseur cloud](doc:glossary#provider).

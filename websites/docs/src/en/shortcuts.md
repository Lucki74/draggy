Shortcuts work from anywhere in the window. <kbd>Ctrl</kbd>+<kbd>/</kbd> (<kbd>⌘</kbd><kbd>/</kbd> on macOS) opens the same list inside the app.

| Shortcut | macOS | Action |
| --- | --- | --- |
| <kbd>Ctrl</kbd>+<kbd>K</kbd> / <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>P</kbd> | <kbd>⌘</kbd><kbd>K</kbd> / <kbd>⌘</kbd><kbd>Shift</kbd><kbd>P</kbd> | Open command palette |
| <kbd>Ctrl</kbd>+<kbd>/</kbd> | <kbd>⌘</kbd><kbd>/</kbd> | Show keyboard shortcuts sheet |
| <kbd>Ctrl</kbd>+<kbd>B</kbd> | <kbd>⌘</kbd><kbd>B</kbd> | Toggle sidebar |
| <kbd>Ctrl</kbd>+<kbd>N</kbd> | <kbd>⌘</kbd><kbd>N</kbd> | New chat or session |
| <kbd>Ctrl</kbd>+<kbd>,</kbd> | <kbd>⌘</kbd><kbd>,</kbd> | Open settings |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>D</kbd> | <kbd>⌘</kbd><kbd>Shift</kbd><kbd>D</kbd> | Open diff pane |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>B</kbd> | <kbd>⌘</kbd><kbd>Shift</kbd><kbd>B</kbd> | Open browser pane |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>T</kbd> | <kbd>⌘</kbd><kbd>Shift</kbd><kbd>T</kbd> | Open a new terminal tab (project open) |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>L</kbd> | <kbd>⌘</kbd><kbd>Shift</kbd><kbd>L</kbd> | Open plan pane (Code) |

| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>M</kbd> | <kbd>⌘</kbd><kbd>Shift</kbd><kbd>M</kbd> | Select permission mode |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>I</kbd> | <kbd>⌘</kbd><kbd>Shift</kbd><kbd>I</kbd> | Select model |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>E</kbd> | <kbd>⌘</kbd><kbd>Shift</kbd><kbd>E</kbd> | Select reasoning effort |

| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>F</kbd> | <kbd>⌘</kbd><kbd>Shift</kbd><kbd>F</kbd> | Project files |
| <kbd>Ctrl</kbd>+<kbd>\</kbd> | <kbd>⌘</kbd><kbd>\</kbd> | Close the active pane |

| <kbd>F6</kbd> | <kbd>F6</kbd> | Cycle focus through sidebar, transcript, composer, and dock |

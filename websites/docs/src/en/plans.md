---

For work that takes several steps, the model writes its plan down first, as a checklist, and keeps it up to date.

## Steering it

Tick a step, move it up or down, remove it, or add one. If a task stops before the list is finished, the panel offers **Carry on with the plan**.

## Background tasks

Each conversation runs its own task, and the task keeps going while you work in another one.

- A running conversation is listed under **Working** in the sidebar
- A **Finished** notice appears if it ends while you are elsewhere
- A task waiting on an approval waits in its own conversation

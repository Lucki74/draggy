---
title: "Atajos de teclado"
description: "Todos los atajos de la aplicación, para Windows, Linux y macOS."
section: reference
---

Los atajos funcionan desde cualquier punto de la ventana. <kbd>Ctrl</kbd>+<kbd>/</kbd> (<kbd>⌘</kbd><kbd>/</kbd> en macOS) abre la misma lista dentro de la aplicación.

| Atajo | macOS | Acción |
| --- | --- | --- |
| <kbd>Ctrl</kbd>+<kbd>K</kbd> / <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>P</kbd> | <kbd>⌘</kbd><kbd>K</kbd> / <kbd>⌘</kbd><kbd>Shift</kbd><kbd>P</kbd> | Abrir la paleta de comandos |
| <kbd>Ctrl</kbd>+<kbd>/</kbd> | <kbd>⌘</kbd><kbd>/</kbd> | Mostrar la hoja de atajos de teclado |
| <kbd>Ctrl</kbd>+<kbd>B</kbd> | <kbd>⌘</kbd><kbd>B</kbd> | Mostrar u ocultar la barra lateral |
| <kbd>Ctrl</kbd>+<kbd>N</kbd> | <kbd>⌘</kbd><kbd>N</kbd> | Nuevo chat o sesión |
| <kbd>Ctrl</kbd>+<kbd>,</kbd> | <kbd>⌘</kbd><kbd>,</kbd> | Abrir ajustes |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>D</kbd> | <kbd>⌘</kbd><kbd>Shift</kbd><kbd>D</kbd> | Abrir el panel de diferencias |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>B</kbd> | <kbd>⌘</kbd><kbd>Shift</kbd><kbd>B</kbd> | Abrir el panel del navegador |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>T</kbd> | <kbd>⌘</kbd><kbd>Shift</kbd><kbd>T</kbd> | Abrir una pestaña de terminal nueva (con un proyecto abierto) |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>L</kbd> | <kbd>⌘</kbd><kbd>Shift</kbd><kbd>L</kbd> | Abrir el panel de plan (Code) |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Space</kbd> | <kbd>⌘</kbd><kbd>Shift</kbd><kbd>Space</kbd> | Entrar en el modo Hablar |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>M</kbd> | <kbd>⌘</kbd><kbd>Shift</kbd><kbd>M</kbd> | Elegir el modo de permisos |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>I</kbd> | <kbd>⌘</kbd><kbd>Shift</kbd><kbd>I</kbd> | Elegir modelo |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>E</kbd> | <kbd>⌘</kbd><kbd>Shift</kbd><kbd>E</kbd> | Elegir el esfuerzo de razonamiento |
| <kbd>1</kbd>, <kbd>2</kbd>, <kbd>3</kbd> | <kbd>1</kbd>, <kbd>2</kbd>, <kbd>3</kbd> | Responder a una aprobación pendiente |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>X</kbd> | <kbd>⌘</kbd><kbd>Shift</kbd><kbd>X</kbd> | Cambiar entre chat y código |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>F</kbd> | <kbd>⌘</kbd><kbd>Shift</kbd><kbd>F</kbd> | Archivos del proyecto |
| <kbd>Ctrl</kbd>+<kbd>\</kbd> | <kbd>⌘</kbd><kbd>\</kbd> | Cerrar el panel activo |
| <kbd>Ctrl</kbd>+<kbd>O</kbd> | <kbd>⌘</kbd><kbd>O</kbd> | Recorrer el detalle de la transcripción: Normal, Pensando, Detallado |
| <kbd>Ctrl</kbd>+<kbd>Tab</kbd> | <kbd>Ctrl</kbd>+<kbd>Tab</kbd> | Cambiar entre sesiones recientes |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Tab</kbd> | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Tab</kbd> | Sesión anterior |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>B</kbd> | <kbd>⌘</kbd><kbd>Alt</kbd><kbd>B</kbd> | Enviar el comando en marcha al segundo plano |
| <kbd>@</kbd> | <kbd>@</kbd> | Mencionar un archivo en el compositor |
| <kbd>F6</kbd> | <kbd>F6</kbd> | Recorrer el foco entre la barra lateral, la transcripción, la zona de escritura y el dock |
| <kbd>Esc</kbd> | <kbd>Esc</kbd> | Detener la generación o cerrar la superposición activa |

Что это значит

Модель может смотреть на картинку, только если рядом с ней есть второй файл, который называется проектором изображений. Draggy загружает этот файл вместе с моделью, когда в репозитории он есть, и запускает модель с ним. Если движку не удается загрузить проектор, Draggy запускает модель без него, чтобы текстовый чат продолжал работать. С этого момента модель не принимает изображения, и отправка картинки отклоняется с этим сообщением.

Почему проектор может не загрузиться

Движок понимает фиксированный набор типов проекторов. Проектор неизвестного ему типа отклоняется. Некоторые модели поставляются с проектором, который может прочитать только измененная сборка llama.cpp, и говорят об этом на собственной странице. Draggy запускает стандартный релиз llama.cpp, поэтому такие модели можно использовать для текста, но не для изображений.

Что делать

  • Отправьте сообщение снова, без изображения. Модель по-прежнему работает с текстом.
  • Выберите другую модель с распознаванием изображений в списке моделей: Настройки → Модели.
  • Перезапуск Draggy или повторная загрузка модели заставят Draggy еще раз попробовать проектор. Это стоит сделать после обновления Draggy.

Что это значит

У каждой модели есть окно контекста: объем текста, который она может удержать сразу. Ваши сообщения, ее ответы, результаты инструментов и прикрепленные файлы входят в этот объем. Этот запрос больше окна, с которым запущен движок, поэтому движок его отклонил.

Что делать

  • Начните новый чат. Старый останется в истории.
  • Уменьшите предел сжатия в Настройки → Модели, чтобы Draggy раньше сворачивал старые сообщения.
  • Увеличьте Окно контекста в том же месте. Большее окно требует больше памяти, поэтому модель, которая спокойно помещалась, может перестать помещаться. Если это произошло, см. недостаточно памяти.
  • Прикрепляйте меньше за раз. Длинный файл или большая вставка могут заполнить небольшое окно сами по себе.

Что это значит

Модель использует инструмент, записывая структурированный вызов: имя инструмента и его аргументы. Перед ответом движок проверяет каждый вызов в беседе, и если какой-то составлен неверно, например без типа или с аргументами, которые он не может разобрать, движок отклоняет весь запрос, а не угадывает.

Неверный вызов может быть тем, который модель только что написала, или уже лежать в истории чата. Тогда повторная отправка снова завершится ошибкой.

Что делать

  • Отправьте сообщение снова. Разовая оплошность обычно не повторяется.
  • Если ошибка повторяется, начните новый чат. Так неверный вызов уберется из истории.
  • Используйте более крупную модель или отключите часть инструментов. Небольшая модель с большим числом включенных инструментов может вызывать их ненадежно.

Что делать

  • Подождите немного и отправьте сообщение снова.
  • Если загрузка не заканчивается, см. модель слишком долго загружалась.

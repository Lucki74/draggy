Ce que cela signifie

Un modèle ne peut regarder une image que s'il a un second fichier à côté de lui, appelé projecteur d'image. Draggy télécharge ce fichier avec le modèle quand le dépôt en propose un, et démarre le modèle avec. Quand le moteur n'arrive pas à charger le projecteur, Draggy démarre le modèle sans lui pour que la discussion par texte continue de fonctionner. Le modèle ne peut alors plus recevoir d'images, et en envoyer une est refusé avec ce message.

Pourquoi le projecteur peut ne pas se charger

Le moteur comprend un ensemble fixe de types de projecteurs. Un projecteur d'un type qu'il ne connaît pas est refusé. Quelques modèles en fournissent un que seule une version modifiée de llama.cpp sait lire, et l'indiquent sur leur propre page. Draggy utilise la version standard de llama.cpp : ces modèles servent donc pour le texte, mais pas pour les images.

Que faire

  • Renvoyez le message sans l'image. Le modèle fonctionne toujours pour le texte.
  • Choisissez un autre modèle de vision dans la liste de Paramètres → Modèles.
  • Redémarrer Draggy, ou télécharger à nouveau le modèle, lui fait réessayer le projecteur. C'est utile après une mise à jour de Draggy.

The short version

Draggy sends no telemetry and needs no account. Your chats and settings stay on your computer. Some things do leave it: a cloud provider you add receives your conversations, web searches send their queries to a search provider, and a few requests go out by default, such as update checks and ad-block lists. The sections below list each one. Conversations never go to this website.

The app: what stays on your computer

Chats, settings, the document index, statistics and extension credentials are stored in Draggy's data folder on your own disk. API keys and extension credentials are encrypted with your operating system's keystore. The ChatGPT sign-in is a file in the same folder. Claude decides how its own sign-in is stored. The model that answers you is a process on your computer, reached over 127.0.0.1.

SystemFolder
Windows%APPDATA%\Draggy
macOS~/Library/Application Support/Draggy
Linux~/.config/draggy (settings) and ~/.local/share/draggy (models and chats)

Delete that folder to remove everything Draggy keeps, including the sign-in files. On Windows, Claude Code also keeps a working folder in %ProgramData%\Draggy. Uninstalling the app does not delete it, so a reinstall still has your chats.

The app: what reaches the network

Some of these requests start when you ask for something, such as a download or a search. Others start on their own, such as update checks and ad-block lists. Each service below sees your IP address and whatever the request contains, and handles it under its own policy.

To keep requests to a minimum, set web search to Off, leave extensions off, add no cloud provider, and turn off the ad blocker in the browser pane. Draggy still makes one connection check at startup while no model is installed. Model downloads and first-use speech models also need the network.

This website

draggy.org is a static site hosted on Vercel. It loads nothing from other servers. Like any host, Vercel receives your IP address and the address of the page you ask for, and may keep standard server logs.

The site counts visits with Vercel Web Analytics, served from draggy.org itself. Vercel Web Analytics does not use cookies. It recognises a visit by a hash of the request, which Vercel discards after 24 hours. It records the page, the page you came from, your approximate location, and your browser, operating system and type of device.

The site stores one thing in your browser, and only when you use the control that sets it. Your language is kept in a cookie called draggy-lang. It is set only when you pick a language from the menu, and it lasts one year. The colors follow your system's light or dark setting, and nothing is stored for that.

When you arrive without a language choice, the site uses the first language your browser asks for that it offers. If there is none, it uses the country your request comes from, which Vercel works out from your IP address at that moment. The site does not keep that country.

Download links go to releases on GitHub, which is GitHub's service under GitHub's policy.

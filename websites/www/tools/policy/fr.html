En bref

Draggy n'envoie aucune télémétrie et ne demande aucun compte. Vos discussions et vos réglages restent sur votre ordinateur. Certaines données en sortent tout de même : un fournisseur cloud que vous ajoutez reçoit vos conversations, les recherches web envoient leurs requêtes à un moteur de recherche, et quelques requêtes partent par défaut, comme la vérification des mises à jour et les listes du bloqueur de publicités. Les sections ci-dessous les détaillent une à une. Les conversations ne vont jamais sur ce site.

L'application : ce qui reste sur votre ordinateur

Les discussions, les réglages, l'index des documents, les statistiques et les identifiants des extensions sont stockés dans le dossier de données de Draggy, sur votre propre disque. Les clés d'API et les identifiants des extensions sont chiffrés par le trousseau de votre système d'exploitation. La connexion ChatGPT est un fichier de ce même dossier. Claude décide lui-même comment sa connexion est stockée. Le modèle qui vous répond est un processus de votre ordinateur, joint par 127.0.0.1.

SystèmeDossier
Windows%APPDATA%\Draggy
macOS~/Library/Application Support/Draggy
Linux~/.config/draggy (paramètres) et ~/.local/share/draggy (modèles et discussions)

Supprimez ce dossier pour effacer tout ce que Draggy conserve, y compris les fichiers de connexion. Sous Windows, Claude Code garde aussi un dossier de travail dans %ProgramData%\Draggy. Désinstaller l'application ne le supprime pas : une réinstallation retrouve donc vos discussions.

L'application : ce qui passe par le réseau

Certaines de ces requêtes partent quand vous demandez quelque chose, comme un téléchargement ou une recherche. D'autres partent d'elles-mêmes, comme la vérification des mises à jour et les listes du bloqueur de publicités. Chaque service ci-dessous voit votre adresse IP et ce que la requête contient, et la traite selon sa propre politique.

Pour limiter les requêtes au minimum, réglez la recherche web sur Désactivé, laissez les extensions éteintes, n'ajoutez aucun fournisseur cloud et désactivez le bloqueur de publicités dans le volet du navigateur. Draggy effectue tout de même une vérification de connexion au démarrage tant qu'aucun modèle n'est installé. Les téléchargements de modèles et les modèles vocaux utilisés pour la première fois ont aussi besoin du réseau.

Ce site

draggy.org est un site statique hébergé chez Vercel. Il ne charge rien depuis d'autres serveurs. Comme tout hébergeur, Vercel reçoit votre adresse IP et l'adresse de la page demandée, et peut conserver des journaux de serveur standard.

Le site compte les visites avec Vercel Web Analytics, servi depuis draggy.org même. Vercel Web Analytics n'utilise pas de cookies. Il reconnaît une visite grâce à une empreinte de la requête, que Vercel supprime au bout de 24 heures. Il enregistre la page, la page d'où vous venez, votre position approximative, ainsi que votre navigateur, votre système et le type de votre appareil.

Le site enregistre une seule chose dans votre navigateur, et seulement lorsque vous utilisez la commande qui la crée. Votre langue est gardée dans un cookie nommé draggy-lang. Il n'est créé que lorsque vous choisissez une langue dans le menu, et il dure un an. Les couleurs suivent le réglage clair ou sombre de votre système, et rien n'est enregistré pour cela.

Si vous arrivez sans avoir choisi de langue, le site prend la première langue demandée par votre navigateur et qu'il propose. Sinon, il prend le pays d'où vient votre requête, que Vercel déduit de votre adresse IP à ce moment-là. Le site ne conserve pas ce pays.

Les liens de téléchargement mènent aux versions publiées sur GitHub, un service de GitHub soumis à la politique de GitHub.

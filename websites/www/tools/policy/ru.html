Кратко

Draggy не отправляет телеметрию и не требует учетной записи. Ваши чаты и настройки остаются на вашем компьютере. Некоторые данные все же его покидают: облачный поставщик, которого вы добавите, получает ваши разговоры, поиск в интернете передает запросы поисковому сервису, а несколько запросов уходят по умолчанию, например проверка обновлений и списки блокировщика рекламы. Ниже перечислено каждое из них. Разговоры никогда не попадают на этот сайт.

Приложение: что остается на вашем компьютере

Чаты, настройки, индекс документов, статистика и данные входа в расширения хранятся в папке данных Draggy на вашем диске. Ключи API и данные входа в расширения зашифрованы хранилищем ключей вашей операционной системы. Вход в ChatGPT хранится файлом в той же папке. Способ хранения собственного входа Claude определяет сам Claude. Модель, которая отвечает вам, это процесс на вашем компьютере, к которому Draggy обращается через 127.0.0.1.

СистемаПапка
Windows%APPDATA%\Draggy
macOS~/Library/Application Support/Draggy
Linux~/.config/draggy (настройки) и ~/.local/share/draggy (модели и чаты)

Чтобы удалить все, что хранит Draggy, включая файлы входа, удалите эту папку. В Windows Claude Code также хранит рабочую папку в %ProgramData%\Draggy. Удаление приложения ее не стирает, поэтому после переустановки чаты сохранятся.

Приложение: что уходит в сеть

Часть запросов начинается, когда вы что-то просите, например загрузка или поиск. Другие начинаются сами, например проверка обновлений и списки блокировщика рекламы. Каждый сервис, указанный ниже, видит ваш IP-адрес и содержимое запроса и обрабатывает его по собственной политике.

Этот сайт

draggy.org это статический сайт, который размещен на Vercel. Он ничего не загружает с других серверов. Как и любой хостинг, Vercel получает ваш IP-адрес и адрес запрошенной страницы и может хранить стандартные серверные журналы.

Сайт считает посещения с помощью Vercel Web Analytics, который отдается с самого draggy.org. Vercel Web Analytics не использует cookie. Посещение он распознает по хешу запроса, который Vercel удаляет через 24 часа. Он записывает страницу, с которой вы пришли, примерное местоположение, а также браузер, операционную систему и тип устройства.

Сайт сохраняет в вашем браузере только одну вещь, и только когда вы пользуетесь элементом управления, который ее задает. Выбранный язык хранится в cookie с именем draggy-lang. Он задается только тогда, когда вы выбираете язык в меню, и действует один год. Цвета следуют светлой или темной настройке вашей системы, и для этого ничего не сохраняется.

Если вы приходите без выбора языка, сайт использует первый язык из тех, что запрашивает ваш браузер и которые есть на сайте. Если такого нет, сайт использует страну, из которой пришел запрос, которую Vercel определяет по вашему IP-адресу в этот момент. Сайт эту страну не сохраняет.

Ссылки на загрузку ведут к релизам на GitHub. Это сервис GitHub, и он действует по политике GitHub.

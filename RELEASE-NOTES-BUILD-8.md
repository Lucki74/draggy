**Updates**

- Interactive question cards let models ask for choices, multiple selections, or free-form text input directly in chat
- A question session bar displays questionnaire progress with next, submit, and skip controls
- Question history cards allow expanding and reviewing previous answers
- Settings under Chat Preferences configure question timeouts, auto-skip behavior, and toggling interactive questions
- Image attachments and pasted images in the composer display thumbnail preview cards with one-click removal
- Skills can be invoked through slash commands in both Chat and Code modes
- Native macOS and Linux builds reach parity with Windows for file browsing, diff reviews, terminal tabs, and canvas tools
- Streamlined tool execution by running code directly through project terminal commands

**Fixes**

- Removed the unreliable explore subagent in favor of direct search and file reading tools
- Prevented star notice popups from appearing during video recordings and demos
- Updated project dependencies and action workflows

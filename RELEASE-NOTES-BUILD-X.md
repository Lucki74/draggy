**Updates**

- Draggy updates itself on Windows, macOS and Linux. It checks at every launch and every 6 hours, installs a found update in a small window and relaunches. There is no Updates setting anymore
- Every tool call shows live in the chat. Its name and arguments appear while the model is still writing them, and the steps stay with the chat when you reopen it
- Read only tool calls run in parallel
- Deep research: new Deep research, Fact check, News brief and Trend scan skills read sources, keep them in a research library and cite them in the answer
- Assistant turns are redesigned, with the work a turn did folded into one summary, and the diff panes, history and git graph are reworked on every platform
- Russian replaces Chinese as an interface language
- AMD graphics cards use the ROCm build of llama.cpp automatically when one is published
